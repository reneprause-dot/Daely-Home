Kategorien

Version & Aktualisierung

Installierte Version: 2.2.0. Prüft die auf GitHub veröffentlichte version.json. „Hard aktualisieren“ leert nur den App-/Service-Worker-Cache und lädt die Oberfläche neu; lokale Kalenderdaten bleiben erhalten.

Noch nicht geprüft.

Kioskmodus & Bearbeitungsschutz

Nach 2 Minuten ohne Eingabe wird im Kioskmodus ein ruhiger Bildschirmschoner angezeigt. Eine Berührung öffnet wieder die Agenda.

Bearbeitungsschutz: noch nicht eingerichtet.

Die PIN ist eine praktische Zugriffsschranke innerhalb der App, keine Verschlüsselung der Daten und kein Ersatz für Android-Geräteschutz.

Privatsphäre

Termine und Aufgaben bleiben auf diesem Gerät. Es wird kein Konto benötigt. Wetter und externe Kalender benötigen eine Internetverbindung.

GitHub Pages veröffentlicht den Programmcode, nicht automatisch deine lokalen IndexedDB-Daten.
